JellyBuster Link Test

Can two devices connect directly, using Jellyfin only to introduce them?

1. Sign in to Jellyfin

The password goes only to your Jellyfin server and isn't saved. Each device can use the same account or a different one.

2. Pair the devices

You signed in through this computer's own address. On the other device, use this computer's network address instead, such as http://192.168.x.x:8096.

On one device, choose Host. On the other, wait for it to appear below and choose Join.
